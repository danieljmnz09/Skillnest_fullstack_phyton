Guía de Conceptos Web

  • Solicitud POST: Envía datos de forma oculta en el cuerpo del mensaje HTTP para guardar o actualizar información en el servidor.
  • Solicitud GET: Solicita o consulta recursos/páginas al servidor sin modificar el estado de la aplicación.
  • redirect(): Envía una respuesta HTTP (código 302) ordenando al navegador realizar una nueva solicitud a una URL distinta.
  • ¿Por qué request.form llega vacío tras un redirect? Porque `redirect()` genera una nueva petición HTTP independiente de tipo `GET`, destruyendo el cuerpo de la petición `POST` original.
